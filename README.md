# YouTube Comments Extractor

Proiect Python pentru extragerea comentariilor populare de la un videoclip YouTube și salvarea lor într-un fișier YAML.

## Funcționalități

* extragerea comentariilor populare
* extragerea autorului
* extragerea datei
* extragerea conținutului comentariului
* salvare în fișier YAML

## Biblioteci folosite

* youtube-comment-downloader
* PyYAML
* BeautifulSoup4

## Rulare

```bash
pip install -r requirements.txt
python main.py
```
